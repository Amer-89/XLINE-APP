# X-LINE Staff Web Edition
نسخة ويب أولية من X-LINE Staff مبنية على ملف الموظفين المرفق. الواجهة تعمل من المتصفح بعد نشرها على Streamlit Community Cloud.

## الوظائف المضمنة
- تسجيل الدخول وصلاحيات مدير/موظف.
- وحدات PS4 وPS5 والبلياردو وتنس الطاولة.
- بدء الجلسة وإيقافها مؤقتاً واستئنافها وإنهاؤها وحساب التكلفة والفاتورة.
- إضافة المشروبات إلى الجلسات وإدارة قائمة المشروبات.
- سجل الجلسات، البحث، الفلاتر اليومية/الأسبوعية/الشهرية، وتنزيل CSV.
- إغلاق اليوم وإعادة فتحه، وتصدير ملف نقل JSON للمحاسب.
- إعداد الأسعار والحد الأدنى، وإدارة المستخدمين وتغيير كلمات المرور.
- واجهة عربية/إنجليزية.

## مهم قبل الاستخدام المالي الحقيقي
هذه الحزمة تستخدم SQLite محلياً. على استضافة Streamlit Community Cloud، نظام الملفات المحلي ليس مخزناً دائماً مضموناً؛ قد تضيع البيانات عند إعادة النشر أو إعادة تشغيل البيئة. **لا تستخدمها لتسجيل معاملات حقيقية قبل ربطها بقاعدة بيانات دائمة** (مثل PostgreSQL مُدارة) واختبار النسخ الاحتياطي. لا ترفع قاعدة البيانات أو كلمات المرور إلى GitHub.
كما أن تسجيل الدخول الافتراضي لأول تشغيل هو `admin` / `admin123`؛ غيّر كلمة المرور فوراً، ولا تنشر رابطاً عاماً دون تقييد الوصول.

## النشر على Streamlit Community Cloud
1. أنشئ مستودع GitHub جديداً باسم `x-line-staff-web`.
2. ارفع الملفات: `app.py` و`requirements.txt` و`.gitignore`.
3. افتح https://share.streamlit.io/ وسجّل الدخول بحساب GitHub.
4. اختر **Create app** ثم المستودع والفرع `main` والملف `app.py`.
5. انشر التطبيق؛ ستعطيك المنصة رابطاً حقيقياً من نوع `https://....streamlit.app`.
6. الرابط لا يصبح فعالاً إلا بعد النشر الفعلي من حسابك.

## تشغيل محلي للاختبار
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
